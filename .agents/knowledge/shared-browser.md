# Shared Browser

`browser_ownership.ts` reserves hosting for the first accepted start requester. The smallest joined actor serializes reservations and transfers current ownership when coordination changes; finishing or losing the host releases the reservation. Browser state is bound to the current owner and ownership term, independently of room authority or the app creator. Joined participants send actor-bound commands to that host over the existing admitted app transport. The host serializes input, rejects replayed sequences and stale tab/session targets, and invalidates queued commands across membership changes. Pending motion is coalesced per actor between button/key/navigation barriers; the authoritative virtual cursor updates independently of slow renderer completion. Mouse, keyboard and text renew a single control lease; viewport exit immediately hides the virtual cursor, frees control and invalidates queued input; otherwise idle control expires after one second, held gestures have a loss timeout, and local host input preempts remote control. Held keys/buttons are released on handoff. Ordinary page input uses absolute viewport coordinates. Offscreen pointer lock is adapted by `browser_pointer_lock.js`: a trusted engagement gesture requests a bounded telemetry report, and the host binds capture to the accepted input owner. The controlling shell surface captures its local mouse, batches relative movement per display frame and forwards it only through that owner’s session/tab-bound commands. The locked lease does not idle-expire; Escape, lost window focus, UI teardown, navigation, participant departure and host takeover release capture and held input. Relative events are synthesized in the requesting page frame, so games requiring trusted raw events or browser-native pointer-lock internals need compatibility checks. The host’s physical mouse is never captured by an offscreen page. Script dialog answers bypass the input queue because the originating click can be paused by the dialog itself. The current browser host can stop the session without removing the room app or discarding its persistent profile.

`shared_browser.rs` creates isolated WebView2 windows for tabs. Every window starts blank and is configured before navigating to third-party content; new sessions without saved pages and new tabs open Google. The device-local hardware-acceleration preference is fixed for all tabs when a browser session starts; changing it offers an explicit restart-now/later dialog. Restart invalidates the old input/media session, retains ownership and tab URLs, reuses the profile directory, and passively waits for the old owned browser process to exit before applying new arguments. InPrivate memory ends with that process, so temporary-session accounts can be signed out. `browser_runtime.rs` supplies WebView2 rendering arguments without changing the shell or native capture encoder preferences. App-generated browser labels have no capabilities, application commands explicitly reject browser callers, and WebView2 web messages are disabled. Public navigation accepts bounded HTTP(S) URLs and blank pages, excluding application origins. Native enumeration additionally admits enabled installed extension origins for host-opened extension interfaces. Native methods expose typed commands rather than arbitrary scripts or DevTools methods. Native release emits events only for buttons actually held, preventing an idle handoff from synthesizing a right click. Mouse movement derives the active CDP button from its held-button mask so Chromium can maintain native text-selection gestures. `browser_dialogs.rs` retains script dialog COM deferrals on the UI apartment and sends bounded text to the canonical application dialog. Downloads require a host-operated Save dialog.

`browser_capture.ts` uses the canonical `NativeVideoBridge` and a generation-specific native capture session. WGC captures the active app-owned tool window, positioned outside the virtual desktop, without taskbar presence or activation; all tab windows remain live offscreen, and background audio joins the same browser process-tree capture. Selection changes only the video source. `browser_window.rs` confines native position/size changes on the owning UI apartment, including automatic HTML fullscreen promotion, before they expose the capture window. This internal source bypasses only the picker's tool-window exclusion after checking process ownership and visibility. Pixels use the authenticated binary WebSocket bridge rather than per-frame DevTools screenshots or Base64 IPC, keeping capture outside the input operation lock. Native encoder preferences, GPU/readback scaling, bounded delivery, pressure feedback and decoder fallback follow ordinary native screen capture. Tab changes replace the video track while retaining audio and peer connections; profile changes update frame rate and dimensions in place. Native session teardown is also bound to browser closure. Controller3 raw-pixel bounds and explicit rasterization scale keep the logical viewport/input at 1280×720 while producing 720p or 1080p. CDP viewport emulation is not used; native scaling persists across navigation. The optional video probe runs outside the input operation lock.

`browser_navigation.rs` records top-level WebView2 navigation start/completion per tab, guarded by native session generation and navigation ID. Loading and native history-availability events go directly to the trusted shell and then authenticated room snapshots; metadata refresh preserves concurrent navigation state. History flags also cover same-document navigation and gate both toolbar and context actions. The page progress bar is indeterminate. `BrowserTabs` sends relative ID moves, preserving active WebViews while synchronizing and persisting tab order. Its retained list entries become inert during exit, with reduced-motion and interrupted-transition handling through `useListPresence`. Scoped shortcut capture handles address selection, history keys/side buttons and reload before page input forwarding. Forced reload uses CDP `Page.reload` with `ignoreCache`, without clearing cookies or site data. `browser_favicon.rs` reads bounded native PNG icons, resizes them and includes them in host snapshots; viewers never fetch favicon URLs independently. Native fullscreen hides tabs and uses an overlay toolbar with the shared idle-controls hook; `useBrowserChrome` preserves explicit local collapse across pointer movement and fullscreen changes, and address focus reopens it; focused controls remain accessible while the page keeps its full area. Native fullscreen transitions are serialized; failed native exits restore dialog interactivity for retries. Fullscreen dialog presence suppresses shell titlebar chrome independently of native resize events.

Reading targets 720p/15 with detail-oriented encoding. `browser_quality.ts` starts playback at 720p/30 and adapts up to the host's saved ceiling using measured native processing and bridge cost. Motion detection runs once per second with a fixed bounded isolated-world probe and three-second grace period. Visible playing videos and prominent visible canvases select the motion profile. Canvas presence is a heuristic, so static canvas applications can also select that profile; the probe does not create graphics contexts or sample protected pixels. A local motion-clarity preference selects bounded WebRTC bitrate ceilings, with congestion adaptation still controlled per peer. Unsupported/protected players can require the host's Video override. Hardware codec availability, protected content and real throughput require interactive desktop verification; native JPEG remains the canonical encoder fallback. WebRTC applies per-viewer congestion adaptation independently of host capture quality and reuses the canonical low-delay video receiver tuning. Local cursor prediction follows display frames without changing host authority; remote cursor updates interpolate briefly, and input motion remains coalesced between ordering barriers.

SDP/ICE use app messages, the room’s Internet/LAN RTC configuration and canonical codec preferences. ICE is buffered until SDP publication; failed/disconnected connections renegotiate. Browser process-tree WASAPI capture owns an independent stop flag and event name, preserving ordinary screen audio capture. Viewer audio uses `AudioContextManager`; host playback remains native. `browser_audio.rs` applies host-local gain/mute through render-session `ISimpleAudioVolume`, restricted to the isolated browser process tree across active output devices. A separate worker discovers later sessions and restores original mixer levels on teardown; it never adjusts page media or the process-loopback samples sent to peers. Local gain is absent from room snapshots. Media, cookies, local paths and extension settings are absent from room snapshots.

One browser session can run per application process, with up to sixteen tabs. Persistent data lives under the dedicated app-local `SharedBrowser` directory, separate from the shell and personal browsers. URL lists and the active tab are saved locally; reopening reloads pages rather than restoring in-memory DOM state. Temporary sessions use unique directories and InPrivate mode. Reset selects a fresh profile generation and retries deletion of the previous directory after closing its WebViews; downloaded files are retained. Cache, history and site data have separate cleanup actions. `browser_extension_packages.rs` imports host-selected ZIP/CRX files or unpacked folders into bounded profile-owned storage and a local registry. File-count, byte-size, folder-depth and registry budgets have distinct errors, so large asset catalogs are distinguished from oversized files. Source paths are not retained. `browser_extension_store.rs` validates Chrome Web Store/Edge Add-ons links, downloads bounded packages only through vendor HTTPS endpoints and redirects, then reuses managed import on a blocking worker. Store CRX requests and downloads are intercepted for confirmation in the trusted shell; external protocol launches are cancelled. Native import pickers are parented to the main window. Extension installation, listing, enabling, disabling and removal use the native profile API. Declared popup pages can open as shared extension tabs; extension-specific APIs and active-tab assumptions require desktop compatibility checks.

Browser detachment reuses the canonical app-window host. A device-local model mirror forwards validated actions and request acknowledgments to the main model; native browser IPC remains main-window-only. A local WebRTC relay borrows existing tracks without owning or stopping capture, and carries media to the detached view without room signaling. Closing the view restores the main UI and preserves the session. Native monitor full screen through the canonical fullscreen dialog and website full screen remain available. Closing/leaving the host session stops its browser/media, without host migration. Native `NewWindowRequested` resolves allowed links directly into shell tab requests, guarded by active tab and generation, without holding a COM new-window deferral. New-window links become shared tabs; retaining popup opener relationships, native browser-toolbar popups, automatic extension updates, browser sync, remote native file pickers and arbitrary system permission dialogs are outside this implementation. Protected media and individual extension/site compatibility require interactive desktop checks.

Tab labels accept middle-button close without selecting the tab; close activity captures the original title before native removal. Accepted browser navigation commands produce actor-bound activity messages tied to the current host term/session, without snapshot replay or pointer/keyboard notifications. `browser_context_menu.rs` handles native page-context requests without opening offscreen OS menus. The host routes bounded context metadata only to the actor whose accepted right-click requested it; the trusted shell renders canonical context actions and uses that actor's local clipboard. Ctrl+C uses a bounded isolated-world selection probe that follows focused frames and open shadow inputs without reading the host OS clipboard. Session-bound copy requests return text only to the requesting actor; that client writes its own clipboard. Device-local RPC results carry text back to detached windows. Selection text is absent from snapshots. Context menus are transient and absent from snapshots. Browser operation failures use the shared dismissible toast lifecycle rather than persistent inline state. Model and signaling regressions run without hardware. User-operated checks should cover two desktop instances, simultaneous input and host takeover, typing/IME/paste, tab navigation, website dialogs and full screen, audio alongside screen sharing, profile persistence/reset, temporary session closure and unpacked extensions. Automated packaging and policy tests do not establish live WebView rendering or cross-machine compatibility.

Page zoom uses bounded native controller steps stored per tab and travels in browser state. Capture publishes the tab associated with its current video source; the presentation overlay waits for that source and visible decoded frames instead of document loading. A small temporary video sample is used only during source transitions, with an escape for genuinely black live content.

`browser_cursor.rs` installs bounded cursor telemetry through a private CDP isolated-world binding. Enable the CDP Page agent before registering navigation scripts; registration alone does not activate injection. Cursor reports use microtasks rather than animation frames because offscreen rendering can pause. A separate bounded main-world binding reports game pointer-lock requests without exposing application IPC. The cursor probe derives text, clickable and default shapes from page hit testing without overriding selection policies or enabling page IPC. Native generation and active-tab checks precede shell events; host-authenticated cursor packets include shape, tab and browser-session identity. `useBrowserCursor` merges shape updates with local position prediction without rewinding the cursor. Native cursor suppression belongs to the contained video-sized cursor layer, leaving letterbox bars outside its hit area; the drawn cursor itself never intercepts input. Detached mirrors receive the same pointer shape through local snapshots.
